# Brain Design Decisions

Why this brain is designed the way it is. One record per question, numbered.

**Belongs here:** decisions about the brain itself: its structure, formats, and rules.

**Doesn't belong:** decisions about a project (those live in that project's repo), and
engineering principles (`principles/`).

**Format:** frontmatter (`summary`, `read-when`), then Context, Decision, Alternatives
rejected, Consequences. When a decision changes, edit its record in place and move the old
answer to "Alternatives rejected" with why it was dropped; git keeps the old text. A new
number is only for a new question. When a question no longer matters, delete its record and
leave its number unused.
